# ECE 2171 Lab 6 Starter Code (Fall 2026)

Starter files for Lab 6: Interrupts (Particle Photon).

This repository contains four Particle Workbench projects: `Lab6a`, `Lab6b`, `Lab6c`, and `Lab6d`. Each `src/Lab6x.cpp` file is an empty program. Lab6a starts from your Lab1c code, Lab6b from your Lab6a code, Lab6c from your Lab6b code, and Lab6d is a new program (the alarm system).

## Getting your own copy

1. Click **Use this template** (top right) and select **Create a new repository**.
2. Name your repository `ece2171-lab6-<username>`, set the visibility to **Private**, and click **Create repository**.
3. In your new repository, click **Code**, select **HTTPS**, and copy the URL.
4. In a VS Code terminal: `cd H:\ECE2171` then `git clone <your-copied-repo-URL> Lab6`
5. In VS Code, choose **File -> Open Folder** and open the `Lab6a` folder (later `Lab6b`, `Lab6c`, `Lab6d`).

See the Lab 6 handout on Brightspace for the full instructions.
